# MOSP技能基础使用示例

## 1. 语音控制

### 语音输入示例
```
"开始MSR计算，生成Pt55团簇"
"修改温度参数到400K"
"执行KMC模拟，反应类型=CO氧化"
"显示当前的参数设置"
```

### 语音识别配置
- 使用Whisper tiny模型
- MOSP专业术语自动修正
- 支持中英文混合输入

## 2. MSR团簇结构生成

### 基本命令
```python
# 在OpenClaw中调用
使用mosp-msr技能
金属类型：Pt
团簇大小：55
温度：300K
对称性：Ih
```

### 生成输出
- 团簇结构文件（.xyz格式）
- 静态结构图（PNG）
- 旋转动画（GIF）
- 能量收敛曲线

## 3. KMC动力学模拟

### 反应设置
```python
使用mosp-kmc技能
反应体系：CO氧化
金属表面：Pt(111)
温度范围：300-500K
时间步长：1e-9秒
模拟步数：1000000
```

### 输出结果
- TOF（周转频率）随温度变化
- 表面物种覆盖度
- 反应网络图
- 反应路径分析

## 6. 故障排除

### 常见问题

**Q1: 语音识别不准确**
- 确保环境安静
- 使用清晰的科学术语发音
- 检查Whisper模型是否正确加载

**Q2: 计算不收敛**
- 检查初始参数设置
- 增加模拟步数
- 调整温度范围

**Q3: 结果可视化问题**
- 确认matplotlib已安装
- 检查图像保存路径权限
- 调整图形参数

## 7. 高级功能
